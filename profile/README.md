# isIPsafe

**Is that IP safe?**

Free IP reputation lookups, attack reports and firewall blocklists for sysadmins and developers.

[**Open isipsafe.com**](https://isipsafe.com) &nbsp;|&nbsp; [GitHub](https://github.com/isipsafe) &nbsp;|&nbsp; [GitLab](https://gitlab.com/isipsafe) &nbsp;|&nbsp; [LinkedIn](https://www.linkedin.com/company/isipsafe-com) &nbsp;|&nbsp; [X](https://x.com/isIPsafe)

</div>

---

## What you can do

| | |
|---|---|
| **Check** | Look up the reputation of any IP address before you trust it. |
| **Report** | Send in abusive IPs, such as brute-force attempts, so others can block them. |
| **Block** | Download firewall blocklists and keep your firewall in sync. |

Everything below is open source. Pick the one that fits where you already work.

## Use it where you work

### Libraries and command line

| Repo | What it does | Language | License |
|---|---|---|---|
| [isipsafe-python](https://github.com/isipsafe/isipsafe-python) | Official Python client and CLI: check IP reputation, report abusive IPs and download firewall blocklists. | Python | MIT |
| [isipsafe-js](https://github.com/isipsafe/isipsafe-js) | Official JavaScript/TypeScript client and CLI: check IP reputation, report abusive IPs and download blocklists. | TypeScript | MIT |

### Run it as a container or server

| Repo | What it does | Language | License |
|---|---|---|---|
| [isipsafe-docker](https://github.com/isipsafe/isipsafe-docker) | Docker image: check and report IPs, and keep a firewall blocklist in sync. | Shell | MIT |
| [isipsafe-digitalocean](https://github.com/isipsafe/isipsafe-digitalocean) | 1-Click Droplet for the DigitalOcean Marketplace: Ubuntu with fail2ban reporting and an isIPsafe blocklist. | Shell | MIT |

### Plug it into other tools

| Repo | What it does | Language | License |
|---|---|---|---|
| [isipsafe-wordpress](https://github.com/isipsafe/isipsafe-wordpress) | WordPress plugin: block known attackers at login and report brute-force attempts. | PHP | GPL-2.0 |
| [isipsafe-zapier](https://github.com/isipsafe/isipsafe-zapier) | Zapier integration: check IP reputation, report IPs and watch the blocklist. | JavaScript | MIT |
| [n8n-nodes-isipsafe](https://github.com/isipsafe/n8n-nodes-isipsafe) | n8n community node: check IP reputation, report IPs and download blocklists. | TypeScript | MIT |
